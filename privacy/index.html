Privacy Policy

Last updated: 9 September 2026

Sereinora is an independent brand and project.

This Privacy Policy explains how Sereinora handles information in connection with its services and its use of Google and YouTube API Services.

Google and YouTube API Services

Sereinora uses Google OAuth and YouTube API Services to manage Sereinora-controlled YouTube channels.

Sereinora uses Google OAuth and YouTube API Services to:

  • publish Sereinora audiovisual releases that have been explicitly approved for publication;
  • verify the authorized Sereinora YouTube channel;
  • retrieve limited information about recent Sereinora YouTube uploads; and
  • retrieve YouTube Analytics information for Sereinora's own channel and releases.

Sereinora currently requests the following Google OAuth permissions:

  • youtube.upload, to upload approved videos to an authorized YouTube channel;
  • youtube.readonly, to retrieve authorized YouTube channel and video information; and
  • yt-analytics.readonly, to retrieve authorized YouTube Analytics information.

These permissions are used only for the functionality described above.

Information Accessed and Stored

Depending on the operation performed, Sereinora may access and locally store:

  • OAuth authorization credentials;
  • authorized YouTube channel identity information;
  • limited recent-upload information, including provider video identifiers, publication dates and privacy states;
  • YouTube Analytics daily rows and coverage information; and
  • delivery information needed to verify an authorized upload and prevent duplicate publication.

OAuth credentials are stored using secure credential storage controlled by Sereinora.

Authorized channel, upload and Analytics information used by Sereinora is stored locally in storage controlled by Sereinora.

Sereinora does not request, collect or store your Google or YouTube password.

How Google and YouTube Data Is Used

Google and YouTube API data is used only to operate Sereinora's authorized YouTube publishing, verification and analytics functionality.

Sereinora does not sell Google or YouTube user data.

Sereinora does not use Google or YouTube user data for advertising.

Sereinora does not transfer Google or YouTube Authorized Data to advertising platforms, data brokers, third-party analytics services, OpenAI, Buffer or unrelated third parties.

The Google and YouTube services themselves necessarily receive information required to provide OAuth, YouTube Data API and YouTube Analytics API functionality.

Sereinora's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including applicable Limited Use requirements.

Retention

Sereinora retains Google and YouTube API data only for as long as required for the authorized operational purpose and in accordance with applicable Google and YouTube API requirements.

YouTube Analytics data may be retained while the relevant authorization remains active, subject to the authorization and data-validity checks required by YouTube.

Other stored YouTube API data is refreshed or deleted within the periods required by YouTube's Developer Policies.

Sereinora does not retain independently calculated metrics derived from YouTube API Data where such derivation is prohibited by YouTube's Developer Policies.

Revoking YouTube Access

Sereinora provides a Revoke YouTube Access control for its YouTube authorization.

Because Google's authorization semantics apply across the relevant Sereinora Google project, using this control revokes Sereinora's YouTube authorization for both publishing and read/Analytics functionality.

On successful revocation, Sereinora removes the applicable locally stored OAuth credentials and Authorized Data in accordance with YouTube's requirements.

You may also revoke access independently through Google's account security and third-party access settings.

Revoking Sereinora's authorization or deleting locally stored Sereinora data does not delete videos or other content stored by YouTube. Content hosted on YouTube must be managed separately through YouTube or another appropriately authorized client.

Deletion

A user may request deletion of applicable Google or YouTube data stored by Sereinora through Sereinora's deletion controls or by contacting Sereinora.

Applicable stored user data will be deleted as soon as possible and within the periods required by YouTube's Developer Policies.

Deleting locally stored data does not delete data or videos stored by YouTube.

Security

Sereinora uses technical and operational safeguards appropriate to the data and current use.

OAuth credentials are stored using secure credential storage. Publishing credentials and read/Analytics credentials are maintained separately.

Sereinora does not intentionally expose Google or YouTube Authorized Data to unrelated external services.

Google and YouTube Policies

Use of functionality involving YouTube API Services is also subject to YouTube's Terms of Service.

Sereinora's use of information received from Google APIs is governed by applicable Google API policies.
